# Mundo das Aventuras

Portal de jogos de estudo da família. Abra pelo link do GitHub Pages.

- `index.html`: o portal (perfis, jogos, lojinha, minijogos, fliperama, área do pai)
- `dados/`: um arquivo por jogo de estudo, mais o jogo do fliperama `arcade-queimada.js`
- `roteiros/`: roteiros de estudo abertos pelos jogos
